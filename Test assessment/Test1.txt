3.Methods in java:
Method is the special form of functions which help to perform various operations 

4.Method overloading:
If the name of the instance variable and the name of the variables inside the parantesis of the methods are same then the concept overloading will occurs.

5.Constructor:
Constructors are the special methods in java which helpful for the initilization and it helps to create the instances with the help of new keyword .
java consist of implicit and explicit form of constructors.

6.Types of constructors :
there are 2 types of constructors
1.Implicit constructor
2.Explicit constructor
Implicit constructors are the default constructors which was generated by the complier.
Explicit constructor are the constructor which was generated by the developer based on the requirements.

7.This keyword:
this keyword is used to varify that the variables name are from the class means when the instance variable names and the parameterized constructor or method variables names are same on that time to specify that the names are from the class instance we use this keyword.

8.class Things{
	
	String name;
	int price;
	double rating;
	
	Things(String name,int price,double rating){
		this.name=name;
		this.price=price;
		this.rating=rating;
	}
	void display(){
		System.out.println("the name is:"+this.name);
		System.out.println("the price is:"+this.price);
		System.out.println("the rating is:"+this.rating);
		
	}
}

class ThingsRunner{
	public static void main(String[] args){
		Things things=new Things("fan",200,4.5);
		things.display();
		
	}
}
